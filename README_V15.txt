V15 — PDF de una sola página

Esta versión parte de la V14 revisada. El cambio principal es el diseño compacto del PDF para que la cotización/notas se generen en una sola hoja A4 siempre que el contenido pueda acomodarse. No se elimina información: se reducen márgenes, tamaños y espacios.

IMPORTANTE: al actualizar una instalación PWA existente, cierre la aplicación por completo y vuelva a abrirla para que el Service Worker V15 reemplace la caché anterior.
