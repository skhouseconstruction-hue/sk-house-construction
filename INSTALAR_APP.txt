SK HOUSE CONSTRUCTION — APP INSTALABLE

Esta versión conserva la aplicación web y agrega soporte PWA para instalarla como aplicación en Android, Windows, macOS, Linux y iPhone/iPad (según navegador).

ANDROID (Chrome):
1. Abre la dirección HTTPS de la aplicación.
2. Espera unos segundos.
3. En Chrome toca ⋮ > "Instalar aplicación" o "Agregar a pantalla principal".
4. Confirma. La aplicación aparecerá como SK House Construction.

WINDOWS (Chrome/Edge):
1. Abre la dirección HTTPS.
2. Busca el icono de instalar en la barra de direcciones, o usa el menú del navegador > "Instalar SK House Construction".
3. Confirma.

IMPORTANTE:
- Para que el navegador permita la instalación PWA, la aplicación debe publicarse mediante HTTPS (tu dominio workers.dev funciona con HTTPS).
- La base de datos de Supabase sigue funcionando en línea; instalar la app no elimina la necesidad de Internet para sincronizar datos.
- No compartas la clave service_role de Supabase. En la aplicación debe utilizarse únicamente la clave pública/publishable correspondiente y políticas RLS correctamente configuradas.
